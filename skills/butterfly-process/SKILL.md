# Butterfly Process

Apply the canonical Butterfly Process methodology for product architecture work.

## Before any task

1. Read `docs/methodology/butterfly-process/BUTTERFLY-PROCESS.md` (v1.0.0)
2. Identify the current chapter / phase
3. Delegate to the matching chapter skill when the task is phase-specific

## Two loops (core model)

**Sense loop** (boucle du sens): intuition → empathie → définition → feedback terrain

**Incarnation loop** (boucle de l'incarnation): prototypage → design → développement → livraison

These loops run in parallel and spiral — never treat the process as a one-way waterfall.

## Output discipline

- Early phases: tensions and HMW questions, not solutions
- Prototyping: hypotheses made tangible, intentionally imperfect
- Definition: temporary compass, not permanent truth
- Always cite which Butterfly chapter guides the current work
