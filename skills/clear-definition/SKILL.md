# Clear Definition

Chapter 3. Extract a living tension; do not jump to solutions.

## Workflow

1. **Synthesize** research — group verbatims, map issues, note contradictions
2. **Zoom / recul** — surface symptom vs structural failure
3. **Formulate tension** — open enough to explore, precise enough to guide
4. **HMW** — "Comment pourrions-nous… ?" / "How might we… ?"
5. **Align team** — shared tension, not total consensus
6. **Mark as temporary compass** — will be challenged and refined

## Good HMW examples

- Comment pourrions-nous réduire la solitude dans les processus de création ?
- Comment pourrions-nous reconnecter les gens à leurs intuitions ?

## Trap formulations (reject)

- "How might we add advanced filters?" → already a solution
- "How might we improve our product?" → too vague
- "How might we convince users to use feature X?" → assumes feature is right

## Questions for synthesis

- What returns most often?
- What provokes emotion?
- Where are contradictions and discomfort?
- What does it say more deeply?

## Output

- Tension statement (1–2 sentences)
- 1–3 HMW questions
- Visual synthesis (optional): issue map, verbatim clusters
- Alignment note: who shares this tension?
