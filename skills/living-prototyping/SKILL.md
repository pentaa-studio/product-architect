# Living Prototyping

Chapter 4. Materialize intention to learn — not to convince.

## Principles

- Prototype = hypothesis made tangible
- Imperfect on purpose — polish kills honest feedback
- Test context, not only product UI (pricing, partnerships, community appetite)

## Before showing

State intent in ~10 seconds:

> *Ceci n'est pas une solution aboutie, mais une hypothèse que je teste. J'aimerais savoir ce que ça éveille chez toi.*

## Prototype forms

- Paper sketch, clickable mockup, role-play scenario
- Fake landing page + ads, pitch simulation
- Faux Slack/Discord community to test appetite
- Symbolic prototypes: letter, audio message, printed mind map

## Context prototypes

| Test | Method |
|------|--------|
| Pricing | Landing + targeted ad |
| Partnership | Co-branded content |
| Community | Invite-only channel, observe retention |
| Ecosystem MVP | Before technical MVP |

## Loop

Prototype → test → learn → adjust → re-prototype (permanent movement)

## Output

- Prototype artifact (low fidelity preferred)
- Test protocol: who, what question, what signal counts
- Learning log: what was misunderstood, what resonated
