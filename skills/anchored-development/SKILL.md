# Anchored Development

Chapter 6. Build without betraying sense — development as craft, not execution.

## Mindset

- Developers translate vision sensitively; they are artisans of structure
- Permanent product ↔ tech dialogue (not throw-over-the-wall specs)
- Tech constraints can **reshape** product for 80/20 value

## Product-tech loop

1. Make it work (validate intention)
2. Make it right (clarify, readable, humane code)
3. Make it fast (optimize when justified)

Leave room for iteration and early dev involvement in discovery.

## Conscious shipping

Anticipate invisible debt:

- Security neglected → future breach
- Accessibility ignored → exclusion
- Fragile architecture → growth ceiling

Launch is birth, not finish.

## Workflow

1. Trace each build item to tension / HMW / validated prototype
2. Involve engineering in scope — seek simpler path with most value
3. Define done: functional + ethical + sustainable
4. Plan feedback loop back to sense loop after release

## Output

- Scoped backlog items with tension traceability
- Trade-off log (what was cut and why)
- Post-launch sensing plan (support, analytics, qual)
