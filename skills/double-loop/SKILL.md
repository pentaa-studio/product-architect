# Double Loop

Chapter 7. Two wings, one body — breathe between sense and incarnation.

## The two loops

**Sense loop (boucle du sens)**

Intuition → empathie → définition → (new tensions from field)

**Incarnation loop (boucle de l'incarnation)**

Prototypage → design → développement → livraison → (usage feedback)

They **nourish each other continuously** — not once, not sequentially.

## Spiral, not circle

Each pass deepens: more just, more informed, more aligned.

## Team mapping

Different people may sit in different loops at the same time — all necessary.

Facilitator keeps clarity on which loop is active for the project moment.

## Anti-drifts

| Drift | Symptom | Correction |
|-------|---------|------------|
| Linear rigidity | Plan everything upfront | Re-open sense loop |
| Chaotic motion | Build without compass | Re-assert tension / HMW |

## Workflow

1. Map current work to sense or incarnation loop
2. Ensure discovery stays 1–2 cycles ahead of delivery (dual-track)
3. When new tension emerges post-launch → sense loop, not feature factory
4. Document which loop each ritual serves

## Output

- Loop map for current initiative
- Identified gap (e.g. shipping without recent empathy)
- Next ritual per loop
